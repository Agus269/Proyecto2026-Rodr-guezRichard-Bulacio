# Recursos visuales

Las seis ilustraciones de productos y el favicon son SVG originales creados
para este proyecto con asistencia de Codex. Son ilustraciones orientativas,
no fotografías de comida ni imágenes oficiales de una marca.

Los archivos son locales y se cargan mediante `img` con texto alternativo.
El favicon utiliza el mismo esquema de colores del sitio.

Las fuentes Lora y Nunito Sans se solicitan a Google Fonts desde la hoja CSS;
si no hay conexión se usan Georgia y Arial. No se descargó un template de sitio.
